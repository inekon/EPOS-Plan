# EPOS-Plan

EPOS-Plan ist die Planungs- und Simulationssoftware von INEKON für Energie- und
Wärmeversorgungskonzepte — Wärmebedarf, Brauchwasser, Prozesswärme, Heizkessel, BHKW,
Wärmepumpe, Solarthermie, Photovoltaik, Speicher und Klimadaten, dazu Simulation, Berichte
und Wirtschaftlichkeitsrechnung; das Repository trägt den Rechenkern `EPOS.Kern`, die
plattformfreie Oberfläche `EPOS.UI`, die Windows-Anwendung und die iOS-Hülle.

Die Arbeitsregeln stehen in [`CLAUDE.md`](CLAUDE.md) — je Projekt eine weitere in
`EPOS.Kern/`, `EPOS.UI/`, `EPOS.iOS/` und `WindowsFormsApplication1/`.

Sämtliche Fach-, Konzept- und Protokollpapiere liegen unter `Dokumentation/`, geordnet nach
`aktuell/` (gültige Arbeitsgrundlage) und `ueberholt/` (Geschichte); der Index dazu ist
[`Dokumentation/LIESMICH.md`](Dokumentation/LIESMICH.md).
