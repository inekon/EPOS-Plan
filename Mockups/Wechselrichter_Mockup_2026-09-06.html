M4 — der Rechenweg je Stunde: Module → Strang → MPPT → Wechselrichter → Clipping → AC. Die Zahlen sind die des Beispiels (10 Module Ablytek 6MN6A275 an einem Muster 2500TL) in einer Sommermittagsstunde mit 950 W/m² auf der Modulebene.

1 – 2 · Modul und Strang

n_s     = Module_Reihe · Straenge_Parallel
P_STC,s = n_s · Leistung_Modul / 1000
T_Zelle = T_amb + G_t/800 · (T_NOCT − 20)
P_DC,s  = P_STC,s · G_t/1000 · (1 + γ·(T_Zelle − 25))

Im Modell ERWEITERT tritt an die Stelle der letzten Zeile das Huld-Schwachlichtmodell; die Einstrahlung kommt dann aus Hay-Davies. Neigung und Azimut sind die des Strangs, sonst die der Anlage.

3 – 4 · MPPT und Wechselrichter

P_DC,mppt = Σ_{s ∈ MPPT} P_DC,s
P_DC,ger  = (Σ_{mppt ∈ Gerät} P_DC,mppt)
            · (1 − Systemverluste/100)
x         = P_DC,ger / P_AC,nenn
η_WR(x)   = Interpolation über 5/10/20/30/50/100 %

Unter der kleinsten Stützstelle linear auf null, über 100 % konstant η100 — dahinter greift das Clipping, kein weiter fallender Wirkungsgrad.

5 – 6 · Clipping, Nacht, Summe

P_AC,roh = P_DC,ger · η_WR(x)
P_AC,ger = min(P_AC,roh, P_AC,nenn)
falls P_DC,ger < P_Standby/1000:
    P_AC,ger = −P_Nacht/1000
P_AC,Anlage = Σ_{Geräte} P_AC,ger

Clipping-Verlust = Σ max(0, P_AC,roh − P_AC,nenn); Wechselrichterverlust = Σ (P_DC,ger − P_AC,roh). Beides geht ins Protokoll und auf die PV-Karte.

Auslegungsprüfung (P1 – P4)

P1  n · [U_oc + β·(−10 − 25)]  ≤ U_Dc_Max
P2  n · [U_mpp + β·(70 − 25)]  ≥ U_Mpp_Min
P3  n · [U_mpp + β·(−10 − 25)] ≤ U_Mpp_Max
P4  p · [I_sc + α·(70 − 25)]   ≤ I_Dc_Max

n = Module in Reihe, p = Stränge parallel je MPPT. β ist negativ (V/K), α positiv (A/K). Für U_mpp gibt es keinen eigenen Koeffizienten — P2 und P3 nehmen β, wie die Auslegungspraxis auch.

Kennlinie aus Sandia (nur beim Import)

bei U_dc = U_dco gilt A = Pdco, B = Pso, C = C0:
P_AC(P_DC) = [Paco/(Pdco − Pso) − C0·(Pdco − Pso)]
             · (P_DC − Pso) + C0·(P_DC − Pso)²

η(x) = x·Paco / P_DC(x)     für x = 0,05 … 1,00

Prüfwert: bei x = 1 ist P_DC = Pdco und η100 = Paco/Pdco exakt. Der Sandia-Rechenweg selbst bleibt liegen — er bräuchte U_dc je Stunde.

Europäischer Wirkungsgrad

η_euro = 0,03·η5  + 0,06·η10 + 0,13·η20
       + 0,10·η30 + 0,48·η50 + 0,20·η100

Ausweis im Katalog und Rückfall, wenn nur dieser eine Wert aus dem Datenblatt bekannt ist: Dann wird die Vorgabekurve so skaliert, dass sie ihn trifft.
